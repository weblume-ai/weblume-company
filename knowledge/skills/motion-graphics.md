# Skill: motion-graphics reels (Hassan)
Weblume's approved reels (weblume-ad: Day, Kinetic, Newspaper, Never Closed, Cafe) teach the rules:
- Second 0-1 decides everything: open with a "hook" or "kinetic" scene that states the pain or the promise in 2-5
  words, big. Never open on the logo.
- One idea per scene, 2-4 seconds each, 15-30 seconds in total. Change something on screen at least every 1.5 s.
- Kinetic type is the backbone: few words, huge, one after another ("kinetic"), the last word in red; Arabic words
  whole (never letter by letter).
- Show the real work: the client's site scrolling in a phone ("site"), the real menu, real photos. On a reel about a
  client's site, "image" scenes use that site's own photos (the code picks them); AI photos only for mood when the
  site has none, never to fake a product (no cupcakes for a shop that sells samosa and maamoul).
- Kinetic lines: 3-5 short words. Each word needs half a second on screen and the first one waits for the red wipe,
  so a kinetic scene lasts at least 0.8 s + 0.5 s per word (the code stretches it if you give less).
- Showing the same site twice? The second phone scene opens a different page; give it a caption about a different
  benefit, or use one longer site scene instead.
- Sound: the code lays the music bed of Weblume's approved kinetic reel under every reel and fades it out at the end.
- Numbers only when true ("counter": 3 days to launch, 0 SAR before the design). Never invented sales or clients.
- Rhythm: hook → problem → the site (proof) → one benefit as a counter or kinetic line → the brand reveal ("logo")
  → the call to action (added by the code: the Weblume website, never a phone number).
- Every scene enters with motion (the red wipe, words popping, devices rising); nothing sits still for a whole scene.
- Look: black, red, white (Weblume), or the client's colours when the reel is about the client's site.
- Scene types: hook, text, kinetic, counter, site (phone/laptop), image, logo; the code adds the cta.
Reference skills on this laptop for bigger productions: motion-reel (beat grids, shot lists, critique on contact
sheets) and remotion (React video). Hassan's player draws the reel itself, frame by frame, no paid tools.
