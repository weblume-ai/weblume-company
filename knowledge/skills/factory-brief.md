# Skill: brief the local model (site factory)
The local model (weblume-factory on Asser's laptop) writes the site's content as one JSON file. It is fast and free but
literal: it follows a clear brief well and guesses badly. Your brief removes the guessing.
- FACTS: copy every fact from the request exactly — business name as written, menu items and prices, address, hours,
  WhatsApp, Instagram/TikTok, map link. Never translate or "improve" a name.
- MISSING: list what the request doesn't give (prices, hours, address, photos) so the model writes a placeholder and
  adds it to "review" instead of inventing it as fact.
- DIALECT: Egypt → light Egyptian, currency ج.م; Saudi/Gulf → simple Saudi, ر.س; unclear → easy Arabic.
- IDEA: one idea taken from this business (a grill's fire, a bakery's morning dough, a juice bar's colour). It decides
  the hero line, the colours and the motion.
- COLOURS: name the mood and give hex values in the factory's names: ink = PAGE BACKGROUND, paper = text on it,
  accent, surface (cards), muted, onAccent. Never gold on a dark page.
- MENU PLAN: the client's items first, exactly; then fill each category to 4-6 real, different items named like the
  local menus of this kind of place (their prices are estimates: say so in MISSING).
- PIECES: the piece ids to use, one per type, chosen with the factory-pieces skill.
- WATCH OUT: the 3 mistakes this request invites (e.g. English dish names, a menu of drinks for a grill).
Short lines, no essay. The local model reads English instructions best; the content it writes is Arabic.
