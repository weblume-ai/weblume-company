# Skill: AI image prompts
Write the prompt in English: [subject in detail], [style: professional product photography / cinematic],
[background: brand color], [light: soft studio light, rim light], [angle: 45 degree, close-up],
[lens: 85mm, shallow depth of field]. Always end with "no text, no watermark": Arabic text in AI images comes out
wrong, so text is added later in the video. Keep one fixed part (background + light) across a set so it looks like
one shoot. Sizes: reels/stories 9:16, menu 1:1. Real photos of real work beat AI images whenever they exist.
